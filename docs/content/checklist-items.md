## チェックリストで進捗管理

GFM (GitHub Flavored Markdown) のタスクリスト構文を使うと、
サイドパネルにチェックボックスが表示されます。

```markdown
## サブタスク

- [ ] HTML の基本要素を理解した
- [ ] セマンティックタグを使い分けられる
```

> **注意**: `- [x]` と書いても初期値にはなりません。チェック状態はブラウザの
> localStorage の内容で決まるため、記事を開いた直後は常に未チェックです。

## 保存の仕組み

チェック状態はブラウザの **localStorage** に自動保存されます。

```
localStorage キー: roadmapper:progress
構造: {
  "[roadmapId]": {
    "[nodeId]": {
      "state": "none" | "in-progress" | "done" | "skipped",
      "tasks": [true, false, true, ...]
    }
  }
}
```

ページを閉じても状態が保持され、再度開いたときに復元されます。
チェックの数に応じてノード全体の状態も自動で更新されます (全未チェック=未着手、一部=学習中、全チェック=完了)。
複数デバイスで進捗を共有したい場合は「進捗のバックエンド同期」を参照してください。

## ノード全体のステータス

サイドパネル上部のドロップダウンでノード全体のステータスを手動設定できます。

| ステータス | 意味 |
|---|---|
| `none` | 未着手 (デフォルト) |
| `in-progress` | 学習中 |
| `done` | 完了 |
| `skipped` | スキップ |

## サブタスク

- [ ] `- [ ]` 形式のタスクリストを `.md` に追加した
- [ ] ブラウザでチェックボックスが操作できることを確認した
- [ ] チェック後にページをリロードして状態が保持されていることを確認した
