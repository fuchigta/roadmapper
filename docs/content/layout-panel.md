## layout — 自動レイアウトの調整

ノードの配置は dagre.js で自動計算されます。`site.layout` で向きと間隔を調整できます。

```yaml
site:
  layout:
    rankDir: TB     # TB / LR / BT / RL (既定: TB)
    nodeSep: 50     # 同じ階層のノード間隔 (既定: 50)
    rankSep: 80     # 階層間の間隔 (既定: 80)
```

| 値 | 向き |
|---|---|
| `TB` | 上から下 |
| `LR` | 左から右 |
| `BT` | 下から上 |
| `RL` | 右から左 |

特定のノードだけ位置を固定したい場合は、ノードに `x` / `y` を指定します。

## panel — サイドパネルの幅

ノードをクリックすると開くサイドパネルの幅 (px) を指定できます。

```yaml
site:
  panel:
    width: 520       # 初期幅 (既定: 520)
    minWidth: 320    # 最小幅 (既定: 320)
    maxWidth: 960    # 最大幅 (既定: 960。画面幅の 80% も上限になる)
```

- 未指定の値は、指定済みの値と矛盾しない範囲で既定値に補正されます
- `minWidth <= width <= maxWidth` を満たさないと `validate` がエラーにします。負の値も不可です
- 読者はパネルの境界をドラッグして幅を変更でき、その幅はブラウザに保存され、次回以降は `width` より優先されます (`minWidth` / `maxWidth` の範囲内)
