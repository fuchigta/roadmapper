## 学ぶこと

バックエンド開発では、まず 1 つの言語を深く学ぶことが重要です。
言語ごとの特徴を知ったうえで 1 つを選び、HTTP サーバーを書けるところまで進めましょう。

## サブタスク

- [ ] 候補の言語の特徴と向いている用途を比較できる
- [ ] 学ぶ言語を 1 つ決め、公式チュートリアルを一通り終える
- [ ] 標準ライブラリなどで簡単な HTTP サーバーを書ける
- [ ] CRUD API を作って REST の基本を体験する

## ポイント

- **Go**: シンプルな構文、高い並行処理性能、コンパイル言語。マイクロサービスや CLI ツールに向く
- **Python**: 学習コストが低く、ライブラリが豊富。データ処理や機械学習との連携にも強い
- **Node.js**: フロントエンドと同じ JavaScript で書ける。リアルタイム処理やフルスタック開発に向く
- **Java**: エンタープライズでの採用実績が豊富。Spring Boot などのエコシステムが充実
