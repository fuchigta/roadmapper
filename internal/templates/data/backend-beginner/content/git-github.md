## 学ぶこと

GitHub は Git リポジトリをホストし、共同作業を支えるサービスです。
プルリクエストやイシューを使った開発の流れに慣れておきましょう。

## サブタスク

- [ ] アカウントを作成し、SSH キーなどで認証設定ができる
- [ ] リポジトリを `clone` / `push` できる
- [ ] ブランチからプルリクエストを作成できる
- [ ] イシューでタスクや不具合を管理できる
- [ ] フォークして他人のリポジトリへ貢献する流れを説明できる
