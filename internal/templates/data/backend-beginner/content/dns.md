## 学ぶこと

DNS は `example.com` のような**ドメイン名を IP アドレスに変換**する仕組みです。
サイト公開やメール設定などで必ず関わるため、基本を押さえておきましょう。

## サブタスク

- [ ] ドメイン名から IP アドレスが引かれるまでの流れを説明できる
- [ ] A / AAAA / CNAME / MX / TXT レコードの用途を説明できる
- [ ] `dig` や `nslookup` で名前解決を確認できる
- [ ] TTL とキャッシュの影響を理解している
