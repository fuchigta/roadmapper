## 学ぶこと

Node.js はブラウザの外で JavaScript を動かす実行環境です。フロントエンドと同じ言語で
サーバーを書けるため、フルスタック開発やリアルタイム通信に向いています。

## サブタスク

- [ ] JavaScript の基本文法と非同期処理 (Promise / async-await) を理解している
- [ ] `npm` でパッケージを管理できる
- [ ] 組み込みの `http` モジュールで簡単なサーバーを書ける
- [ ] Express などのフレームワークで API を作れる
