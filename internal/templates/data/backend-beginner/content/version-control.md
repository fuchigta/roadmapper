## 学ぶこと

Git はソースコードの**変更履歴を管理**するツールです。チーム開発はもちろん、
個人開発でも「いつでも戻せる」安心感が得られるため必ず身につけましょう。

## サブタスク

- [ ] リポジトリの作成と基本的なコミットができる
- [ ] ブランチを切って作業し、マージできる
- [ ] リモートリポジトリへ push / pull できる
- [ ] `.gitignore` で不要なファイルを除外できる
