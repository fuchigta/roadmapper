## 学ぶこと

統合テストは、複数のコンポーネント (たとえばアプリと DB) を**実際に組み合わせて**確認するテストです。
ユニットテストでは見つからない、接続部分の不具合を発見できます。

## サブタスク

- [ ] ユニットテストとの違いを説明できる
- [ ] テスト用の DB を用意して実際にクエリを実行できる
- [ ] テストごとにデータを初期化し、独立性を保てる
- [ ] Docker を使ってテスト環境を再現できる
