## 学ぶこと

バックエンドが動く舞台は**インターネット**です。リクエストがどう届き、レスポンスがどう返るのかを
理解すると、後の API 設計やデプロイが格段に分かりやすくなります。

## サブタスク

- [ ] クライアントとサーバーの役割の違いを説明できる
- [ ] ブラウザに URL を入力してから画面が表示されるまでの流れを説明できる
- [ ] HTTP と DNS がそれぞれ何を担っているか説明できる
- [ ] 自分のアプリをどこで公開できるか (ホスティング) を知っている
