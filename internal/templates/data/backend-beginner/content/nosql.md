## 学ぶこと

NoSQL は RDB 以外のデータストアの総称です。Redis はキャッシュ用途に、MongoDB はドキュメント指向の
データ保存によく使われます。用途に応じて RDB と使い分けます。

## サブタスク

- [ ] RDB と NoSQL の得意・不得意を説明できる
- [ ] Redis でキーと値を保存・取得し、有効期限を設定できる
- [ ] MongoDB でドキュメントの保存と検索ができる
- [ ] キャッシュとして使う場面を説明できる
