## 学ぶこと

Terraform は複数のクラウドに対応した代表的な IaC ツールです。HCL という言語で構成を記述します。

## サブタスク

- [ ] provider / resource / variable / output を書ける
- [ ] `init` / `plan` / `apply` の流れを説明できる
- [ ] state の役割と共有 (リモートバックエンド) を理解している
- [ ] モジュールで構成を再利用できる

## ポイント

```bash
terraform init
terraform plan
terraform apply
```
