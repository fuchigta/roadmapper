## 学ぶこと

バージョン管理は変更履歴を記録し、チームで安全に開発するための基盤です。
インフラ定義やスクリプトも Git で管理するのが DevOps の基本です。

## サブタスク

- [ ] リポジトリの作成とクローンができる
- [ ] 変更履歴を確認し過去の状態に戻せる
- [ ] リモートリポジトリ (GitHub / GitLab) と連携できる
- [ ] コードだけでなく設定ファイルも管理する意義を説明できる
