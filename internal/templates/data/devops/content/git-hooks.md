## 学ぶこと

Git フックはコミットやプッシュなどのタイミングでスクリプトを自動実行する仕組みです。
コミット前にフォーマットやリントを走らせ、品質を早い段階で担保できます。

## サブタスク

- [ ] `.git/hooks` にあるフックの種類を説明できる
- [ ] pre-commit フックを自作できる
- [ ] pre-commit などのツールでフックを共有できる
- [ ] フックだけに頼らず CI でも同じ検査をする理由を理解している
