## 学ぶこと

AWS CloudFormation は AWS ネイティブの IaC サービスです。JSON または YAML のテンプレートでリソースをスタックとして管理します。

## サブタスク

- [ ] テンプレートの基本構造 (Parameters / Resources / Outputs) を説明できる
- [ ] スタックの作成・更新・削除ができる
- [ ] 変更セットで事前に差分を確認できる
- [ ] Terraform との違いを説明できる
