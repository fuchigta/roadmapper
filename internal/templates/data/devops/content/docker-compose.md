## 学ぶこと

Docker Compose は複数コンテナからなるアプリを YAML 1 ファイルで定義・起動するツールです。ローカル開発環境の構築に便利です。

## サブタスク

- [ ] `compose.yaml` でサービスを定義できる
- [ ] `docker compose up` / `down` を使える
- [ ] サービス間のネットワークと名前解決を理解している
- [ ] 環境変数やボリュームを設定できる

## ポイント

```bash
docker compose up -d
docker compose logs -f
docker compose down
```
