## 学ぶこと

チームでブランチをどう運用するかを決めるのがワークフローです。
GitHub Flow はシンプルで CI/CD と相性が良く、Git Flow はリリース管理が必要な場合に向きます。

## サブタスク

- [ ] GitHub Flow の流れ (ブランチ→PR→レビュー→マージ) を説明できる
- [ ] Git Flow の main / develop / feature / release / hotfix を説明できる
- [ ] プルリクエストを作成しレビューを受けられる
- [ ] チームに合うフローを選ぶ観点を説明できる
