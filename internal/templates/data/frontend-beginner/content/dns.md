## 学ぶこと

DNS は `example.com` のような**ドメイン名**を IP アドレスに変換する仕組みで、
インターネットの電話帳のような役割を持ちます。

## サブタスク

- [ ] ドメイン名から IP アドレスが引かれる流れを説明できる
- [ ] A レコード・CNAME レコードの違いが分かる
- [ ] `nslookup` や `dig` で名前解決を試せる

## ポイント

DNS の設定を変えた直後に反映されないのは、キャッシュ (TTL) が残っているためです。
