## 学ぶこと

Elements パネルで、表示中のページの DOM と適用されている CSS を確認・編集できます。

## サブタスク

- [ ] 要素を選択して HTML 構造を確認できる
- [ ] Styles タブで適用中のスタイルと取り消し線の意味が分かる
- [ ] 値をその場で編集して見た目を試せる
- [ ] ボックスモデルの図で余白を確認できる

## ポイント

DevTools での編集はリロードで消えます。良い変更はソースコードに反映しましょう。
