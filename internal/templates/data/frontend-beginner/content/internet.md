## 学ぶこと

フロントエンド開発者が作ったページは、**インターネット**を通じてブラウザに届きます。
まずは「どこから・どうやって届くのか」の全体像をつかみましょう。

## サブタスク

- [ ] クライアントとサーバーの役割の違いを説明できる
- [ ] URL を入力してページが表示されるまでの流れを大まかに説明できる
- [ ] HTTP と DNS が何をしているか一言で言える

## ポイント

細部を暗記する必要はありません。「リクエストを送り、レスポンスを受け取る」という
往復の形を覚えておくと、後の学習がスムーズになります。
