## 学ぶこと

ES2015 以降に追加された現代的な構文を学び、コードを読みやすく書けるようにします。
実際のプロジェクトではほぼ必須の知識です。

## サブタスク

- [ ] アロー関数とテンプレートリテラルを使える
- [ ] 分割代入とスプレッド構文を使える
- [ ] `import` / `export` でモジュールを分割できる
- [ ] `map` / `filter` など配列メソッドを使える

## ポイント

```js
const { name, age } = user;
const next = { ...user, age: age + 1 };
```
