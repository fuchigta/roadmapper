## 学ぶこと

CSS の土台となる、セレクタ・ボックスモデル・カスケード (優先順位) を学びます。

## サブタスク

- [ ] 要素・クラス・ID・子孫セレクタを書き分けられる
- [ ] `margin` / `border` / `padding` / `content` の関係を説明できる
- [ ] 詳細度と記述順による優先順位を説明できる
- [ ] `box-sizing: border-box` の意味が分かる

## ポイント

```css
.card {
  box-sizing: border-box;
  padding: 16px;
  border: 1px solid #ccc;
}
```
