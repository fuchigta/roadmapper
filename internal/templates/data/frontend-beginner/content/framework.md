## 学ぶこと

フレームワークは、画面を部品 (コンポーネント) に分けて状態に応じた UI を
効率よく作るための道具です。まず 1 つを選んで深く学びましょう。

## サブタスク

- [ ] コンポーネントとは何かを説明できる
- [ ] 状態 (state) の変化で画面が更新される仕組みを説明できる
- [ ] 選んだフレームワークで小さなアプリを作れる

## ポイント

React・Vue・Svelte はどれも考え方が近く、1 つ習得すれば他にも移りやすくなります。
先に JavaScript の基礎を固めておきましょう。
