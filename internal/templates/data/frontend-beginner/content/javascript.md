## 学ぶこと

JavaScript はページに**動き**を与えるプログラミング言語です。ブラウザ上で
ユーザーの操作に反応したり、サーバーと通信したりできます。

## サブタスク

- [ ] 基本構文を使って簡単なプログラムを書ける
- [ ] DOM を操作してページを書き換えられる
- [ ] 非同期処理と API 通信を扱える
- [ ] エラーメッセージを読んで原因を調べられる

## ポイント

このノードが最も時間がかかる部分です。小さなアプリ (ToDo リストなど) を作りながら学びましょう。
