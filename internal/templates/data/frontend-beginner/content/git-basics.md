## 学ぶこと

リポジトリの作成からコミット、ブランチ、マージ、リモートとのやり取りまで、
日常的に使う Git の基本操作を学びます。

## サブタスク

- [ ] `git init` / `git clone` でリポジトリを用意できる
- [ ] `git add` と `git commit` で変更を記録できる
- [ ] `git branch` / `git switch` でブランチを切り替えられる
- [ ] `git merge` でブランチを統合し、簡単なコンフリクトを解消できる
- [ ] `git push` / `git pull` でリモートと同期できる

## ポイント

```bash
git add .
git commit -m "ヘッダーのスタイルを調整"
git push
```
