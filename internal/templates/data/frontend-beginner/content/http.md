## 学ぶこと

HTTP はブラウザとサーバーが会話するためのルールです。HTTPS は HTTP を暗号化し、
通信の盗み見や改ざんを防ぎます。

## サブタスク

- [ ] GET / POST などのメソッドの違いを説明できる
- [ ] 200・301・404・500 などの主なステータスコードの意味が分かる
- [ ] リクエストヘッダーとレスポンスヘッダーの例を挙げられる
- [ ] HTTPS が必要な理由を説明できる

## ポイント

```http
GET /index.html HTTP/1.1
Host: example.com
```
