## 学ぶこと

変数・関数・条件分岐・繰り返し・データ型といった、言語の基礎を身につけます。

## サブタスク

- [ ] `const` / `let` を使い分けられる
- [ ] 文字列・数値・真偽値・配列・オブジェクトを扱える
- [ ] `if` と `for` で処理の流れを制御できる
- [ ] 関数を定義して呼び出せる
- [ ] `==` と `===` の違いを説明できる

## ポイント

```js
const sum = (a, b) => a + b;
console.log(sum(1, 2)); // 3
```
