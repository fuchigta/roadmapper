## 学ぶこと

チームで安全に開発するための、ブランチの使い方のルール (ブランチ戦略) を知ります。

## サブタスク

- [ ] main ブランチと作業ブランチの役割を説明できる
- [ ] 機能ごとにブランチを切る流れを説明できる
- [ ] プルリクエストを使ったレビューの流れを説明できる

## ポイント

戦略はチームごとに異なります。まずは「main から作業ブランチを切り、レビュー後にマージ」
という基本の形を押さえましょう。
