## 学ぶこと

要素の**意味**に合ったタグを選んで文書の構造を作ります。見た目ではなく意味で選ぶのがコツです。

## サブタスク

- [ ] `<!DOCTYPE html>`・`<head>`・`<body>` の役割を説明できる
- [ ] 見出し `<h1>`〜`<h6>` を階層に沿って使える
- [ ] `<header>` / `<nav>` / `<main>` / `<footer>` で骨格を組める
- [ ] リンク・画像・リストを書ける

## ポイント

```html
<nav>
  <ul>
    <li><a href="/">ホーム</a></li>
  </ul>
</nav>
```
