## 学ぶこと

Vite は、高速な開発サーバーと本番ビルドを提供するビルドツールです。
多くのフレームワークのテンプレートで採用されています。

## サブタスク

- [ ] `npm create vite@latest` でプロジェクトを作成できる
- [ ] `npm run dev` で開発サーバーを起動できる
- [ ] `npm run build` で本番用ファイルを生成できる
- [ ] `vite.config` が何を設定するファイルか説明できる

## ポイント

```bash
npm create vite@latest my-app
cd my-app
npm install
npm run dev
```
