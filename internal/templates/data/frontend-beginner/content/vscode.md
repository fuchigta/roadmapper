## 学ぶこと

Visual Studio Code は、無料で広く使われているコードエディタです。

## サブタスク

- [ ] インストールしてフォルダを開ける
- [ ] コマンドパレットを開いて機能を実行できる
- [ ] 統合ターミナルを使える
- [ ] 検索・置換・複数カーソルなどの編集機能を使える
- [ ] 設定 (settings) を変更できる

## ポイント

コマンドパレットは Ctrl+Shift+P (Mac は Cmd+Shift+P) で開けます。
困ったらまずここで機能名を検索しましょう。
