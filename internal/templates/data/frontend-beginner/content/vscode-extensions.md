## 学ぶこと

拡張機能で、VS Code に言語サポートやコード整形などの機能を追加できます。

## サブタスク

- [ ] マーケットプレイスから拡張機能をインストールできる
- [ ] フォーマッタ (Prettier など) や ESLint を導入できる
- [ ] 不要な拡張機能を無効化・削除できる

## ポイント

入れすぎるとエディタが重くなります。提供元を確認し、本当に使うものだけにしましょう。
