## 学ぶこと

GitHub は Git リポジトリをホストし、共同開発のためのプルリクエストや
Issue などの機能を提供するサービスです。

## サブタスク

- [ ] アカウントを作成してリポジトリを作れる
- [ ] ローカルのリポジトリを GitHub に push できる
- [ ] ブランチを作ってプルリクエストを出せる
- [ ] Issue を作成して管理できる

## ポイント

GitHub Pages を使えば、作った静的サイトを無料で公開することもできます。
