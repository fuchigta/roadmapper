## 学ぶこと

`npm` でパッケージを管理し、`npx` でインストールせずにコマンドを実行する基本を学びます。

## サブタスク

- [ ] `npm init` でプロジェクトを作れる
- [ ] `npm install <パッケージ>` で依存を追加できる
- [ ] `npm run <スクリプト>` を実行できる
- [ ] `npx` の用途を説明できる

## ポイント

```bash
npm install
npm run build
```

`node_modules` は Git にコミットしません。
