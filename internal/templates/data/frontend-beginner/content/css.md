## 学ぶこと

CSS は HTML に**見た目**を与える言語です。色・余白・配置・アニメーションなど、
表現のほとんどを担います。

## サブタスク

- [ ] 外部 CSS ファイルを HTML に読み込める
- [ ] 色・フォント・余白を指定できる
- [ ] レイアウトの基本 (Flexbox / Grid) を使える
- [ ] スマートフォンでも崩れないスタイルを書ける

## ポイント

まずは小さなページに CSS を当て、DevTools で変化を確かめながら進めると定着します。
