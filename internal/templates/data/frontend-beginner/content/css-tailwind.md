## 学ぶこと

Tailwind CSS は、小さなユーティリティクラスを HTML に並べてスタイルを組み立てる
CSS フレームワークです。素の CSS の代替の 1 つとして選べます。

## サブタスク

- [ ] 公式ドキュメントの手順で導入できる
- [ ] 余白・色・文字サイズのクラスを使える
- [ ] レスポンシブ用の接頭辞 (`md:` など) を使える
- [ ] 素の CSS との長所・短所を説明できる

## ポイント

```html
<button class="rounded bg-sky-500 px-4 py-2 text-white">送信</button>
```

先に素の CSS の基本を押さえておくと、クラス名の意味が理解しやすくなります。
