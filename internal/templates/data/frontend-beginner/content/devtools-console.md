## 学ぶこと

Console パネルでエラーや警告を確認し、`console.log` などで値を出力して
プログラムの動作を調べます。

## サブタスク

- [ ] エラーメッセージとその発生場所を読める
- [ ] `console.log` / `console.table` で値を確認できる
- [ ] コンソールで JavaScript を直接実行できる
- [ ] ブレークポイントでコードを一時停止して変数を調べられる

## ポイント

```js
console.log("value:", value);
console.table(users);
```

デバッグ後の不要な `console.log` は削除しておきましょう。
