## 学ぶこと

視覚・聴覚・運動などの状況に関わらず、誰でも使えるページを作る考え方です。
正しい HTML を書くだけで多くの問題は避けられます。

## サブタスク

- [ ] 画像に適切な `alt` を付けられる
- [ ] キーボードだけでページを操作できることを確認できる
- [ ] 見出しやランドマーク要素で構造を伝えられる
- [ ] 文字と背景の十分なコントラストを意識できる

## ポイント

ARIA は HTML のセマンティクスで足りないときの補助です。
まずは標準の要素 (`<button>` など) を使いましょう。
