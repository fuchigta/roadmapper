## 学ぶこと

Network パネルで、ページが行っている HTTP リクエストとレスポンスを確認できます。

## サブタスク

- [ ] リクエスト一覧を表示してステータスコードを確認できる
- [ ] リクエスト・レスポンスのヘッダーと本文を確認できる
- [ ] 読み込みの遅いリソースを見つけられる
- [ ] API 通信の失敗の原因を調べられる

## ポイント

通信エラーの調査では、まず Network パネルでステータスコードとレスポンス内容を確認します。
